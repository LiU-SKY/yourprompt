# Korean prompts, ranked by how much of a request they actually are.
#
# Records are separated by a line of "---". The first line of a record is
# "<tier> <tab> <label>"; everything after it, up to the separator, is the
# prompt exactly as someone would type it.
#
# Tiers are an ordering, not a score. The claim under test is only that a
# prompt in a higher tier outranks one in a lower tier -- the absolute numbers
# are the scorer's business, except where a ceiling is stated below.
#
#   0  not language. Repetition, mashing, jamo, punctuation, filler.
#      Ceiling: must score under 150.
#   1  Korean, but no request in it. Greetings, reactions, thinking aloud.
#      Ceiling: must score under 350.
#   2  a real request, but underspecified -- the deixis and vagueness tier.
#   3  a real request naming something concrete.
#   4  concrete, bounded, and says how to tell when it is done.
#
# Tier 0 is the reason this file exists. A scorer that reads "no ambiguity
# smells" off a prompt that contains no language is measuring the absence of
# evidence and calling it quality.
